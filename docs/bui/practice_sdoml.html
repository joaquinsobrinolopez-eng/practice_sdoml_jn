practice_sdoml package

General description

This package implements the ML complete pipeline for diabetes risk prediction from tabular data

Module componentes

  • practice_sdoml.modeling: Subpaquete encargado de la arquitectura de la red neuronal en PyTorch (SimpleNet), el bucle de entrenamiento (train), la inferencia (predict) y la evaluación de métricas de rendimiento con exportación de figuras.

  • practice_sdoml.config: Define rutas absolutas del proyecto, carga variables de entorno y fija parámetros globales reproducibles.

  • practice_sdoml.dataset: Contiene los scripts y funciones para la descarga, lectura y transformación del archivo diabetes_risk.csv ubicado en data/raw/ a tensores de PyTorch.

  • practice_sdoml.features: Funciones orientadas a la ingeniería de variables, preprocesamiento tabular, codificación de atributos categóricos y normalización de columnas numéricas.

  • practice_sdoml.plots: Módulo de utilidades gráficas para la generación visual de figuras, matrices de confusión, curvas de pérdida y diagramas de calibración.

class practice_sdoml.SimpleNet(input_dim: int, num_classes: int)[source]

Bases: Module

Feedfordward neural network for tabular classification.

This architecture is created of intermediate lineal layers combined with non-linear activation functions (ReLU) to process input characteristics and predict class probability.

Parameters:

  • input_dim (int) – Feature number.

  • num_classes (int) – Total number of classes to predict.

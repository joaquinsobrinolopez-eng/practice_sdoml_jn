Feedfordward neural network for tabular classification.

This architecture is created of intermediate lineal layers combined with non-linear activation functions (ReLU) to process input characteristics and predict class probability.

Parameters:

  • input_dim (int) – Feature number.

  • num_classes (int) – Total number of classes to predict.
